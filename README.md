# PHOTOX — Hacker House Goa Builder Pass

Multi-page generator: Home → Create → Pass, with PNG download and Share on X.

## Run

```bash
npm install
npm run dev
```

## Flow

1. **/** — Eye-catching Goa home (`CREATE`)
2. **/create** — Photo + all builder details (required)
3. **/pass** — Boarding pass preview, Download PNG, Share on X
